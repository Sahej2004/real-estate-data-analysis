# Real Estate Data Analysis

A Python-based data analysis project exploring real estate property data using Pandas, NumPy, Matplotlib, and Seaborn.

## 📌 Project Overview

This project performs exploratory data analysis (EDA) on a real estate dataset to identify patterns and insights related to property prices, area, price per square foot, localities, BHK configurations, property types, builders, and RERA approval.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Analysis Performed

The project analyzes:

1. The costliest flat in the dataset
2. Locality with the highest average property price
3. Locality with the highest average rate per square foot
4. Average price comparison between ready-to-move and under-construction properties
5. Impact of RERA approval on property prices
6. Relationship between property area and price
7. Most expensive BHK configuration based on average rate per square foot
8. Most expensive property type based on average price
9. Top 5 companies with the highest average rate per square foot
10. Relationship between property area and rate per square foot
